# 灵境制造项目 - Trae Code 模式提示词集

本目录包含针对灵境制造项目的改进建议，每个文件都是一个可直接用于 Trae Code 模式的提示词。

## 优先级说明

- **P0 (紧急)**: 影响生产可用性，必须立即修复
- **P1 (重要)**: 影响性能或安全性，建议尽快修复
- **P2 (中等)**: 提升代码质量和可维护性
- **P3 (低)**: 功能增强和优化

## 使用方式

1. 打开 Trae Code 模式
2. 复制对应提示词文件的内容
3. 粘贴到 Trae 的输入框中
4. 根据提示词中的"检测标准"验证修复结果

## 修复顺序建议

### 第一阶段（P0 - 紧急）
1. P0-01: JWT安全修复
2. P0-02: Model Registry单例化

### 第二阶段（P1 - 重要）
3. P1-01: BaseHTTPMiddleware性能优化
4. P1-02: 前端composables合并

### 第三阶段（P2 - 中等）
5. P2-01: 后处理配置扩展

## 注意事项

1. **每个提示词都包含**: 任务描述、当前问题、修复要求、代码示例、检测标准
2. **检测标准是关键**: 完成修复后必须运行检测标准中的测试用例
3. **备份重要**: 修改前请备份相关文件
4. **渐进式修复**: 建议按优先级顺序逐个修复，避免一次性改动过大
