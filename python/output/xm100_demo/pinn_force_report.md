## 说明

- **PINN**: 物理信息神经网络，3→64→64→32→3 残差学习架构
- **Kienzle**: 经典解析解 Fz = kc1.1 × b × h^(1-mc)
- 当 PINN 检查点未训练时，predict_cutting_force() 自动回退到 Kienzle
- 合力 = √(Fx² + Fy² + Fz²)
