# 深度研究工具

## 功能描述
深度研究工具是一个强大的研究助手，帮助用户进行系统性的信息收集、分析和综合。它支持多轮对话、文献检索、数据分析和研究报告生成。

## 主要特点
- **多源信息整合**：从多个来源收集和整合信息
- **系统性分析**：提供结构化的研究方法论
- **文献管理**：支持文献检索、引用和整理
- **报告生成**：自动生成研究报告和摘要
- **迭代优化**：支持多轮对话和持续改进

## 使用场景
- 学术研究：论文写作、文献综述、课题研究
- 市场调研：行业分析、竞品研究、趋势预测
- 技术调研：技术选型、方案评估、最佳实践
- 知识整理：主题学习、知识图谱构建

## 使用方法
1. 明确研究目标和范围
2. 提出具体的研究问题
3. 工具会进行多轮信息收集和分析
4. 生成结构化的研究报告
5. 根据反馈进行迭代优化

## 输出格式
- 研究报告（Markdown 格式）
- 文献列表和引用
- 数据分析和可视化
- 关键发现和建议
