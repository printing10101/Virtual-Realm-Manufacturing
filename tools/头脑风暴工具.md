# 头脑风暴工具

## 功能描述
头脑风暴工具是一个创意生成和思维拓展助手，帮助用户进行发散性思维、创意构思和方案探索。它支持多种创意思维方法和结构化讨论。

## 主要特点
- **发散思维**：支持自由联想和创意发散
- **结构化引导**：提供思维导图、SCAMPER 等方法论
- **多角度思考**：从不同视角审视问题
- **创意评估**：对创意进行可行性分析
- **协作支持**：支持多人协作头脑风暴

## 使用场景
- 产品创新：新功能构思、产品改进、用户体验优化
- 问题解决：复杂问题分析、解决方案探索
- 营销策略：品牌定位、推广方案、活动策划
- 团队建设：团队共创、愿景规划、目标设定

## 使用方法
1. 定义头脑风暴的主题和目标
2. 设定规则和约束条件
3. 进行自由发散思维
4. 整理和分类创意
5. 评估和筛选最佳方案

## 输出格式
- 创意列表和分类
- 思维导图和关系图
- 方案评估矩阵
- 行动计划建议
