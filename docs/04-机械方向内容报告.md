## 一、项目机械领域概述

### 1.1 项目定位

**灵境制造** 是一款面向机械制造行业的 AI 辅助工艺规划与数控编程系统，涵盖从零件设计到数控加工的完整流程：

```
需求描述 → 3D建模 → 工艺规划 → 切削参数 → NC代码 → 机床加工
```

### 1.2 覆盖的机械领域

| 领域 | 覆盖内容 | 说明 |
|------|---------|------|
| CAD 设计 | 三视图识别、参数化建模、3D 模型生成 | AI 辅助设计 |
| 工艺规划 | 加工路线制定、工序编排、设备选择 | 六 Agent 协同 |
| 切削参数 | 切削速度、进给量、背吃刀量、主轴转速计算 | 基于材料和工艺 |
| 数控编程 | G 代码/M 代码自动生成、NC 程序验证 | 标准 ISO 6983 |
| 材料科学 | 金属材料参数、切削性能、热处理 | 知识库支持 |
| 标准规范 | 公差等级、表面粗糙度、形位公差 | 国标/ISO 标准 |

### 1.3 支持的加工类型

| 加工类型 | 支持程度 | 说明 |
|---------|---------|------|
| 车削加工 | ✅ 完整支持 | 外圆、内孔、端面、螺纹车削 |
| 铣削加工 | ✅ 完整支持 | 平面铣、轮廓铣、型腔铣 |
| 钻孔加工 | ✅ 完整支持 | 钻、扩、铰、镗孔 |

## 二、CAD 引擎与三维建模

### 2.1 CadQuery 参数化建模

**技术基础**: CadQuery 2.4+（基于 OpenCASCADE 的 Python CAD API）

#### 2.1.1 参数化建模原理

```python
import cadquery as cq

# 示例：参数化传动轴建模
def create_shaft(diameter, length, keyway_width, keyway_depth):
    # 1. 创建轴主体
    shaft = cq.Workplane("XY").circle(diameter/2).extrude(length)
    
    # 2. 创建键槽
    keyway = (cq.Workplane("XY")
              .workplane(offset=length/2)
              .rect(keyway_width, keyway_depth)
              .cutThruAll())
    
    # 3. 布尔运算
    result = shaft.cut(keyway)
    
    return result

# 生成 STL 模型
model = create_shaft(diameter=30, length=100, keyway_width=8, keyway_depth=4)
model.val().exportStl("output/shaft.stl")
```

### 2.2 三视图识别与 3D 重建

#### 2.2.1 三视图规范

项目支持的工程图三视图遵循 **第一角投影法**（中国国标 GB/T 14692）：

```
┌─────────┐  ┌─────────┐
│  俯视图  │  │  左视图  │
└─────────┘  └─────────┘
┌─────────┐

└─────────┘
```

#### 2.2.2 三视图到 3D 的转换流程

```
用户输入（三视图图片 + 文字描述）
    ↓
UnderstandingAgent 提取关键参数
    ├── 零件类型（轴类、盘类、壳体类）
    ├── 主要尺寸（直径、长度、厚度）
    ├── 特征要素（孔、槽、螺纹、键槽）
    └── 精度要求（公差、粗糙度）
    ↓
AI 推理生成 3D 模型描述
    ↓
CadQuery 参数化建模
    ↓
STL/OBJ 模型输出
    ↓
Three.js 3D 预览
```

## 四、切削参数计算系统

### 4.1 切削参数体系

| 参数 | 符号 | 单位 | 定义 |
|------|------|------|------|
| 切削速度 | v | m/min | 刀具切削刃上选定点相对于工件的主运动的瞬时速度 |
| 进给量 | f | mm/r 或 mm/z | 工件或刀具每转一转（或每齿）时，两者沿进给运动方向的相对位移 |
| 背吃刀量 | ap | mm | 工件上已加工表面和待加工表面间的垂直距离 |
| 主轴转速 | n | r/min | 根据切削速度和刀具直径计算: n = 1000×v / (π×D) |

### 4.2 切削参数计算示例

#### 4.2.1 传动轴精车参数（45钢，φ30，IT7，Ra0.8）

| 工序 | v (m/min) | f (mm/r) | ap (mm) | n (r/min) | 计算依据 |
|------|-----------|----------|---------|-----------|---------|
| 粗车 | 120 | 0.3 | 2.0 | 1273 | 硬质合金刀片，粗加工余量大 |
| 半精车 | 150 | 0.2 | 0.5 | 1592 | 减小进给量，提高表面质量 |
| 精车 | 180 | 0.1 | 0.2 | 1910 | 低进给量，保证 Ra0.8 |

## 九、运动控制逻辑

### 9.1 数控加工运动控制

#### 9.1.1 车床运动控制

```
车床坐标系:
X 轴: 径向（直径编程）
Z 轴: 轴向（平行于主轴）
Y 轴: 无（车床通常为 2 轴）

典型运动:
1. 外圆车削: X 定位 → Z 进给切削
2. 端面车削: Z 定位 → X 进给切削
3. 圆弧车削: G02/G03 圆弧插补
4. 螺纹车削: G76 螺纹循环
```

#### 9.1.2 铣床运动控制

```
铣床坐标系:
X 轴: 左右方向
Y 轴: 前后方向
Z 轴: 上下方向（主轴方向）

典型运动:
1. 平面铣削: X/Y 平面内进给
2. 轮廓铣削: X/Y 插补运动
3. 型腔铣削: Z 分层 + X/Y 轮廓
4. 钻孔: Z 轴进给
```

### 9.2 插补原理

#### 9.2.1 直线插补 (G01)

```
起点 (X0, Z0) → 终点 (X30, Z-100)

插补公式:
ΔX = X_end - X_start
ΔZ = Z_end - Z_start
F = 进给速度

每个插补周期:
ΔX_cycle = F × cos(θ) × T
ΔZ_cycle = F × sin(θ) × T

其中 θ = arctan(ΔZ / ΔX)
```

#### 9.2.2 圆弧插补 (G02/G03)

```
圆弧参数:
X, Z: 终点坐标
R: 圆弧半径
或
I, K: 圆心相对起点的增量

顺圆弧 G02:
刀具沿顺时针方向从起点到终点

逆圆弧 G03:
刀具沿逆时针方向从起点到终点
```

### 9.3 刀具补偿

#### 9.3.1 刀具半径补偿

```
G41: 刀具半径左补偿（沿刀具运动方向看，刀具在工件左侧）
G42: 刀具半径右补偿（沿刀具运动方向看，刀具在工件右侧）
G40: 取消刀具半径补偿

补偿原理:
实际刀具中心轨迹 = 编程轨迹 ± 刀具半径

应用:
精车外圆时使用 G42 补偿
精车内孔时使用 G41 补偿
```

#### 9.3.2 刀具长度补偿

```
G43 H01: 调用 1 号刀具长度正补偿
G44 H01: 调用 1 号刀具长度负补偿
G49: 取消刀具长度补偿

补偿值存储在刀具偏置表中
```
