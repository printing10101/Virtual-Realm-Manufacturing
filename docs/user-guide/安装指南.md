# 安装指南

> 本文档说明如何在不同操作系统上完成灵境制造 v2.0.0 的安装部署，包含环境要求、一键安装脚本、参数说明与安装验证方法。

## 1. 环境要求

### 1.1 硬件最低配置

| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 4 核 x86_64 | 8 核 x86_64，支持 AVX2 |
| 内存 | 8 GB RAM | 16 GB RAM（启用 AI 推理时建议 32 GB） |
| GPU | 可选（CPU 推理即可运行） | NVIDIA GPU，CUDA 11.8+，显存 ≥ 6 GB（启用 GPU 推理加速时） |
| 硬盘 | 10 GB 可用空间 | SSD 50 GB 可用空间（用于模型缓存与项目数据） |
| 网络 | 仅离线运行时无需外网 | 首次部署需要外网拉取模型权重与依赖 |

### 1.2 软件依赖

| 依赖 | 版本要求 | 说明 |
|------|----------|------|
| 操作系统 | Windows 10/11、Ubuntu 20.04+、macOS 12+、Debian 11+、CentOS 8+ | 详见 1.3 兼容性列表 |
| Python | 3.10 / 3.11 | 暂不支持 3.12+（部分 PyTorch 扩展未兼容） |
| Node.js | 18.x / 20.x LTS | 仅在需要前端源码构建时需要 |
| pnpm | 8.x | 前端包管理 |
| Docker | 24.0+ | 可选，容器化部署时需要 |
| Redis | 6.0+ | 可选，用于任务队列与限流计数（单机模式可使用内置内存实现） |
| 浏览器 | Chrome 100+ / Edge 100+ / Firefox 100+ | 访问 Web 端 |
| Tauri Runtime | 2.0+ | 仅使用桌面端时需要 |

### 1.3 操作系统兼容性

| 操作系统 | 状态 | 备注 |
|----------|------|------|
| Windows 11 (x86_64) | ✅ 完全支持 | 桌面端与 Web 端均支持 |
| Windows 10 21H2+ (x86_64) | ✅ 完全支持 | 桌面端与 Web 端均支持 |
| Ubuntu 22.04 LTS | ✅ 完全支持 | 推荐生产环境 |
| Ubuntu 20.04 LTS | ✅ 完全支持 | |
| Debian 11 (Bullseye) | ✅ 支持 | 需手动安装 libgomp1 |
| CentOS Stream 8 / Rocky Linux 8 | ⚠️ 社区支持 | 需启用 EPEL 仓库 |
| macOS 13 Ventura (Apple Silicon) | ⚠️ 实验性 | 部分 AI 模型未提供 MPS 后端 |
| macOS 12 Monterey (Intel) | ✅ 支持 | |
| Windows Server 2019 / 2022 | ✅ 支持 | 仅推荐服务模式 |
| Alpine Linux 3.18+ | ❌ 不支持 | musl libc 与 Rust 仿真引擎存在兼容问题 |

> 标记 ⚠️ 的系统未在 CI 中覆盖，可能存在边缘问题，建议优先在 ✅ 标记的系统上生产部署。

## 2. 获取一键安装脚本

### 2.1 官方获取方式

| 场景 | 方式 | 地址 |
|------|------|------|
| 桌面端（Windows） | GitHub Release 下载 | [Releases](https://github.com/printing10101/Virtual-Realm-Manufacturing/releases) 页面下载 `lingjing-setup-v2.0.0.exe` |
| 服务端一键安装 | curl 下载 | `curl -fsSL https://get.lingjing-mfg.com/install.sh -o install.sh` |
| 服务端一键安装（中国大陆加速） | curl 下载 | `curl -fsSL https://mirrors.lingjing-mfg.com/install.sh -o install.sh` |
| 容器化部署 | docker pull | `docker pull lingjing/manufacturing-api:2.0.0` |
| 源码安装 | git clone | `git clone https://github.com/printing10101/Virtual-Realm-Manufacturing.git --branch v2.0.0` |

### 2.2 校验安装包

下载完成后，**务必校验签名**以避免供应链攻击：

```bash
# 校验 SHA-256
sha256sum lingjing-setup-v2.0.0.exe

# 校验 GPG 签名（仅源码/脚本包提供）
gpg --verify install.sh.asc install.sh
```

官方公布的 SHA-256 指纹会同时发布在 [GitHub Release](https://github.com/printing10101/Virtual-Realm-Manufacturing/releases/tag/v2.0.0) 与 [官网下载页](https://lingjing-mfg.com/download/v2.0.0)。

## 3. 一键安装脚本执行步骤

### 3.1 Linux / macOS

```bash
# 1. 下载安装脚本
curl -fsSL https://get.lingjing-mfg.com/install.sh -o install.sh

# 2. 校验（推荐）
sha256sum install.sh   # 与官网公布指纹比对

# 3. 添加可执行权限
chmod +x install.sh

# 4. 启动安装（交互式）
sudo ./install.sh

# 5. 一键安装（无人值守，按需指定参数）
sudo ./install.sh \
  --mode=server \
  --port=8765 \
  --data-dir=/var/lib/lingjing \
  --admin-user=admin \
  --admin-pass='YourStrongPass!2024' \
  --enable-gpu \
  --enable-redis=redis://localhost:6379
```

### 3.2 Windows（PowerShell）

```powershell
# 1. 以管理员身份打开 PowerShell（必须）

# 2. 允许执行远程脚本（仅本次会话）
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# 3. 下载安装脚本
Invoke-WebRequest -UseBasicParsing -Uri "https://get.lingjing-mfg.com/install.ps1" -OutFile "install.ps1"

# 4. 启动安装（交互式）
.\install.ps1

# 5. 一键安装（无人值守）
.\install.ps1 `
  -Mode server `
  -Port 8765 `
  -DataDir "D:\LingjingData" `
  -AdminUser "admin" `
  -AdminPass "YourStrongPass!2024" `
  -EnableGpu
```

### 3.3 Docker 一键启动

```bash
# 单机开发模式（包含 Redis）
docker run -d \
  --name lingjing \
  -p 8765:8765 \
  -v /var/lib/lingjing:/app/data \
  -e LINGJING_ADMIN_USER=admin \
  -e LINGJING_ADMIN_PASS='YourStrongPass!2024' \
  lingjing/manufacturing-api:2.0.0
```

## 4. 参数说明

### 4.1 公共参数

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--mode` | 否 | `desktop` | 安装模式：`desktop`（桌面端）、`server`（服务端）、`all-in-one`（单机型） |
| `--port` | 否 | `8765` | API 监听端口 |
| `--data-dir` | 否 | `/var/lib/lingjing` (Linux/macOS) / `C:\LingjingData` (Windows) | 数据持久化目录（包含模型缓存、上传工件、项目文件） |
| `--admin-user` | 是 | - | 初始管理员账号 |
| `--admin-pass` | 是 | - | 初始管理员密码（**至少 12 位**，包含大小写字母、数字、特殊字符） |
| `--enable-gpu` | 否 | `false` | 启用 GPU 推理加速（需已安装 CUDA 11.8+） |
| `--enable-redis` | 否 | `memory://` | Redis 连接字符串，格式 `redis://[user:pass@]host:port/db`；使用 `memory://` 表示内置内存模式（不推荐生产） |
| `--log-level` | 否 | `INFO` | 日志级别：`DEBUG` / `INFO` / `WARNING` / `ERROR` |
| `--locale` | 否 | `zh-CN` | 界面语言：`zh-CN` / `en-US` |
| `--skip-os-check` | 否 | `false` | 跳过操作系统兼容性检查（不推荐） |
| `--no-firewall` | 否 | `false` | 安装时不自动配置防火墙规则（自定义网络环境时使用） |

### 4.2 服务端模式专属参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--workers` | `4` | Uvicorn 工作进程数（建议设为 CPU 核心数 × 2） |
| `--behind-cdn` | `false` | 是否部署在反向代理/CDN 之后（影响安全头配置） |
| `--cors-origins` | `*` | 允许的跨域来源（生产环境必须显式指定，多个用逗号分隔） |
| `--tls-cert` / `--tls-key` | - | TLS 证书路径（启用 HTTPS 终止时） |

## 5. 安装验证

### 5.1 进程与端口验证

```bash
# 查看服务进程
ps aux | grep uvicorn | grep -v grep

# 验证端口
curl -fsS http://localhost:8765/api/health/ping
# 预期输出: {"status":"ok"}
```

### 5.2 健康检查端点

| 端点 | 用途 | 预期响应 |
|------|------|----------|
| `GET /api/health/ping` | 进程存活探针 | `200 {"status":"ok"}` |
| `GET /api/health/live` | 轻量级就绪探针 | `200 {"status":"ok"}` |
| `GET /api/health/ready` | 完整就绪探针（含数据库/缓存） | `200 {"status":"ok","components":{...}}` |
| `GET /api/health?detail=true` | 详细组件健康度 | 包含 database / cache / message_queue / model 状态 |

### 5.3 端到端验证脚本

```bash
# 一键运行端到端冒烟测试
python -m app.tests.smoke_test --base-url=http://localhost:8765
```

通过后会输出：

```
[PASS] 登录与令牌获取
[PASS] 工件导入（STEP）
[PASS] 工艺规划（铝件 6061）
[PASS] LNN 推理（切削力预测）
[PASS] 后处理（Fanuc）
[PASS] NC 代码导出

冒烟测试 6/6 通过
```

### 5.4 常见安装失败症状

| 症状 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: No module named 'app'` | 未在 `python/` 目录下启动 | 切换到 `python/` 目录后启动 |
| `OSError: [Errno 98] Address already in use` | 8765 端口被占用 | 使用 `--port` 指定其他端口 |
| `PermissionError: [Errno 13] /var/lib/lingjing` | 数据目录无写权限 | `sudo chown -R $USER /var/lib/lingjing` |
| `torch.cuda.OutOfMemoryError` | GPU 显存不足 | 添加 `--no-gpu` 或降低并发 |
| 安装卡在 `Downloading model weights` | 网络问题 | 切换到 `--mirror cn` 使用中国大陆镜像 |

## 6. 卸载

```bash
# Linux / macOS
sudo ./install.sh --uninstall

# Windows
.\install.ps1 -Uninstall
```

卸载会保留 `data-dir` 下的工件与模型缓存以便重装后继续使用。如需彻底清理：

```bash
sudo rm -rf /var/lib/lingjing
```

> ⚠️ **警告**：上述操作不可逆，请提前备份！
