# 附录

## A. 常见问题排查

### 1. Ollama 连接失败

**症状**：应用显示 Ollama 服务未连接

**排查步骤**：
1. 检查 Ollama 是否启动：`ollama list`
2. 检查端口占用：`netstat -ano | findstr 11434`
3. 确认防火墙未阻止 11434 端口

**解决方案**：
- 启动 Ollama：`ollama serve`
- 修改 `settingsStore` 中的 Ollama URL

### 2. Python 后端启动失败

**症状**：应用无法连接 Python 后端

**排查步骤**：
1. 检查 Python 环境：`python --version`
2. 检查依赖：`pip list | findstr fastapi`
3. 手动启动测试：`cd backend && uvicorn app.main:app --reload`

### 3. ChromaDB 初始化失败

**症状**：调用 `/api/knowledge/health` 返回错误

**解决方案**：
- 删除 `./chroma_db` 目录重建
- 确保路径不包含中文字符

### 4. 3D 模型无法加载

**症状**：ThreeViewer 组件显示空白

**解决方案**：
- 确认浏览器支持 WebGL 2.0
- 更新显卡驱动
- 使用小文件测试

### 5. 工艺规划工作流超时

**症状**：`POST /api/workflow/process-plan` 长时间无响应

**解决方案**：
- 下载推荐模型：`ollama pull qwen2.5:7b`
- 增加请求超时时间

## B. Trae Code 使用技巧

1. **逐 Phase 执行**：严格按照 Phase 0 → Phase 8 的顺序执行
2. **大步骤拆分**：如果某个 Phase 的 Prompt 过长，可以按步骤拆分
3. **验证清单**：每个 Phase 的验证清单是检查修改是否正确的重要参考
4. **错误恢复**：如果某个 Phase 执行失败，修复后重新执行该 Phase 即可
