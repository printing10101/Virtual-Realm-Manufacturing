## 隐私设计原则

**核心原则：数据不出本地设备**

1. **默认本地模式**：所有 AI 推理默认使用本地 Ollama，无需联网
2. **可选云端模式**：用户可自行配置云端 API（OpenAI/DeepSeek 等）
3. **完全离线模式**：提供开关，关闭所有网络请求
4. **数据存储**：所有用户数据存储在本地 `%APPDATA%/lingjing/` 目录
5. **无遥测**：不收集任何用户行为数据

## 使用说明

1. 打开 Trae Code 模式
2. 复制对应 Phase 的完整 Prompt
3. 粘贴到 Trae Code 对话框并执行
4. 等待完成后验证，再进入下一个 Phase

**重要约定**：
- 每个 Prompt 都是自包含的
- 每个 Phase 结束时会生成验证清单
- 如果某个 Phase 执行失败，修复后重新执行该 Phase 即可
