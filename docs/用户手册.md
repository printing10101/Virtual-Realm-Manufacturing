# 灵境制造 LNN AI 系统 - 用户手册

## 1. 系统概述

灵境制造LNN AI系统是基于**神经逻辑网络（Liquid Neural Networks, LNN）**的智能制造推理平台，支持切削力预测、设备磨损预测等工业场景。

### 核心特性

| 特性 | 描述 |
|------|------|
| 智能路由 | 自动选择最优推理引擎（LNN/LLM/Rule/Hybrid） |
| 多模型支持 | CFC快速推理、LTC时序预测、HybridCNN+LNN混合 |
| 在线训练 | 支持后台模型训练与热更新 |
| 高可用性 | 多层降级策略，确保服务连续性 |
| 可解释性 | 完整推理路径与置信度评估 |

## 2. 快速开始

## 3. 使用指南

### 3.1 模型推理

**单样本预测：**

```python
import requests

response = requests.post("http://localhost:8000/api/v1/lnn/predict", json={
    "model_name": "cutting_force",
    "input_data": [[1.2, 0.8, 0.5, 1.0, 0.3]],
    "return_confidence": True
})

print(response.json())
```

**批量推理：**

```python
from app.ai.lnn.inference.batch_inference import BatchInferenceEngine
import numpy as np

engine = BatchInferenceEngine()
results = engine.predict_batch(
    model_name="cutting_force",
    inputs=np.random.randn(100, 5),
    batch_size=32
)
```

### 3.2 模型训练

```python
from app.ai.lnn.training.trainer import LNNTrainer
from app.ai.lnn.models.torch_cfc_model import CFCModel, LNNConfig

# 创建模型
config = LNNConfig(input_size=5, hidden_size=64, output_size=1)
model = CFCModel(config)

# 创建训练器
trainer = LNNTrainer(
    model=model,
    learning_rate=0.001,
    optimizer_type="adam",
    loss_type="mse",
    epochs=100,
    device="cuda"
)

# 训练模型
history = trainer.fit(train_loader, val_loader)

# 导出TorchScript
trainer.export_torchscript("models/my_model.torchscript.pt")
```

### 3.3 使用Bosch数据集

```python
from app.ai.lnn.training.bosch_dataset import BoschDatasetProcessor, BoschDataConfig

config = BoschDataConfig(
    target_columns=["cutting_force"],
    test_size=0.2,
    batch_size=64
)

processor = BoschDatasetProcessor(config)
processor.load_data("data/bosch_dataset.csv")
processor.clean_data()
processor.engineer_features(
    add_lag_features=True,
    add_rolling_stats=True,
)

train_loader, val_loader, test_loader = processor.create_dataloaders()
```

### 3.4 工作流编排

```python
from app.ai.lnn.workflow.workflow_orchestrator import WorkflowLNNOrchestrator

orchestrator = WorkflowLNNOrchestrator()
result = orchestrator.execute_workflow({

```

## 4. 配置管理

### 4.1 配置文件

编辑 `python/config/lnn_workflow.yaml`：

```yaml
lnn:
  enabled: true
  models_dir: "models/lnn"
  default_device: "cuda"
  models:
    cutting_force:
      type: "cfc"
      path: "cutting_force_v1.pt"
    wear_prediction:
      type: "ltc"
      path: "wear_prediction_v1.pt"
  thresholds:
    quick: 0.85
    hybrid: 0.60

workflow:
  enabled: true
  max_steps: 10
  timeout_seconds: 300
  enable_fallback: true
```

### 4.2 环境变量

| 变量 | 描述 | 默认值 |

## 6. 常见问题

**Q: 模型推理速度慢？**
A: 检查是否启用了GPU加速，或使用批量推理提高吞吐量。

**Q: 训练时内存溢出？**
A: 减小batch_size，或启用梯度检查点。

**Q: 如何添加自定义模型？**
A: 继承`BaseLNN`类，实现`forward`和`build`方法，然后注册到引擎。
