## 一、版本概述

V1.11.0 是灵境制造平台面向**工业级制造自动化**的全面升级版本。本版本围绕**安全架构重构**、**LNN AI引擎升级**、**工艺规划引擎增强**、**NC仿真系统升级**、**数据库迁移体系**、**性能基准框架**、**Rust原生计算模块**、**前端架构优化**八大主线展开，共变更 **312个文件**，新增代码约 **30,500行**，删减约 **13,200行**，净增约 **17,300行**。

**V1.11.0核心亮点**:

- 统一认证中间件：3个独立中间件合并为1个纯ASGI中间件，支持JWT/LNN/Agent三Token类型，含Ban List/频率限制/幂等性检查
- 安全头中间件：5个标准安全头自动注入（X-Frame-Options/XSS-Protection/Content-Type-Options等）
- LNN AI引擎双层实现：NumPy(轻量推理) + PyTorch(GPU训练)，支持CFC/LTC/HybridLNN三种架构
- GPU训练完整体系：AMP混合精度、显存监控、自动批大小优化、4种优化器+4种LR调度
- INT8量化支持：动态/静态量化，模型压缩约4x，支持校准和性能对比
- 工艺规划全链条：特征依赖图→3-2-1基准选择→夹具模板匹配→工序排序→工时估算闭环
- NC体素仿真增强：6种刀具类型、ISO 13399合规、STL自动生成、圆弧路径离散化
- Rust计算模块：体素/碰撞/刀路/Rust原生计算引擎预研，预期性能提升50-100x
- Alembic数据库迁移：版本化Schema管理，支持upgrade/downgrade回滚
- 性能基准测试框架：LNN/GCode/Render三类基准，回退检测，CI集成
- 前端10个Composables：Token管理/SSE事件流/3D场景/健康监控/审计日志统一基础设施
- 刀具路径编辑器：G代码可视化编辑、Undo/Redo、3D交互、快捷键
- 规则冲突检测器：矛盾/子集/参数三种冲突类型，≤1000规则<1秒检测

### 2.1 安全架构重构

#### 2.1.1 统一认证中间件

**新增文件**:
- `python/app/core/middleware/unified_auth.py` (914行) — 统一认证ASGI中间件
- `python/app/core/middleware/security_headers_asgi.py` (53行) — 安全头注入中间件

- `python/app/core/auth.py` (181行) — 旧认证中间件
- `python/app/core/jwt_auth.py` (111行) — 旧JWT中间件

**功能说明**:

- **三Token类型统一认证**：JWT(`eyJ...`) / LNN扁平Token(`lj_...`) / Agent Token(`lj_agent_...`)单中间件处理
- **早期路径短路**：公开路径在ASGI层直接放行，零认证开销
- **JWT认证流程**：Ban List检查 → 严格解码(access/refresh) → Token有效性验证
- **LNN认证流程**：HMAC恒定时间比较(防时序攻击) → 权限等级检查 → JWT降级重试
- **Agent认证流程**：Token验证 → 频率限制(60 RPM/3并发) → 权限等级(R/W/B/N/C/T) → 幂等性Key检查 → 审计日志
- **幂等性存储**：写操作强制`Idempotency-Key`头，防止重复提交，缓存执行结果
- **Agent审计日志**：JSONL格式，记录时间戳/Agent ID/路由/权限级别/状态码/延迟
- **Token Ban List**：支持JWT Token撤销，持久化到JSON文件，过期自动清理
- **JWT密钥强制校验**：环境变量`LNN_JWT_SECRET`，无fallback；密钥≥32字符；随机性检测

**影响范围**:
- `python/app/core/middleware/unified_auth.py`
- `python/app/core/middleware/security_headers_asgi.py`
- `python/app/main.py`
- `python/app/config.py`

#### 2.1.2 安全响应头注入

**功能说明**:

| 安全头 | 值 | 防护目的 |

| `X-Content-Type-Options` | `nosniff` | 阻止MIME类型嗅探 |

### 2.2 LNN AI引擎全面升级

#### 2.2.1 双层模型架构

**变更文件**:
- `python/app/ai/lnn/core.py` (+253行) — 核心数据模型升级

- `python/app/ai/lnn/models/parameter_models.py` (+28行) — 参数模型

**功能说明**:

- **NumPy层**：快速原型/轻量推理，目标延迟<100ms
- **PyTorch层**：GPU训练/生产部署，继承`nn.Module + ABC`，支持TorchScript导出
- **CFC模型**：无需ODE求解器，比LSTM快160x，连续液体状态更新`h_new = h + dt * dh`
- **LTC模型**：可学习时间常数τ，核心公式`h_new = h + dt * (tanh(Wx + Uh + b) - h) / τ`，支持最长1000步序列
- **HybridLNN**：CNN + LTC融合，CNN至少3层Conv1d + BatchNorm + MaxPool + AdaptiveAvgPool
- **无缝转换**：`to_torch()`方法从NumPy转PyTorch，实现CPU推理→GPU训练完整链路

## 三、Bug修复与代码改进

### 3.1 认证中间件内存泄漏

**问题**: 旧`AuthMiddleware`/`JwtAuthMiddleware`/`AgentAuthMiddleware`基于`BaseHTTPMiddleware`，缓存完整请求/响应体到内存，高并发时内存泄漏。

**修复**: 迁移到纯ASGI中间件`UnifiedAuthMiddleware`，直接在`scope/receive/send`层面操作，消除body缓存，SSE流完整性保持。

**影响范围**: `python/app/core/middleware/unified_auth.py`, `python/app/core/auth.py`(删除), `python/app/core/jwt_auth.py`(删除)

### 3.2 Agent中间件冗余

**问题**: `python/app/agent/middleware.py`(216行)功能已迁移到统一认证中间件，但旧文件未删除，导致代码冗余和维护混乱。

**修复**: 删除旧Agent中间件文件，功能完全由`unified_auth.py`接管。

**影响范围**: `python/app/agent/middleware.py`(删除)

### 3.3 前端组件逻辑重复

**问题**: 多个组件重复实现Loading/Error管理、SSE连接、localStorage操作、3D场景初始化等逻辑，代码重复率高。

**修复**: 抽取10个Composables形成统一基础设施层，组件复用逻辑，生命周期安全（`onUnmounted`自动清理）。

**影响范围**: `src/composables/`目录新增/变更文件

### 3.4 规则冲突未检测

**问题**: 工艺规则系统中存在矛盾规则（条件相同结论不同），但无检测机制，导致加工参数冲突。

**修复**: 新增`conflict_detector.py`冲突检测器，支持矛盾/子集/参数三种冲突类型，≤1000规则<1秒完成检测。

**影响范围**: `python/app/rules/conflict_detector.py`

### 3.5 后处理器配置硬编码

**问题**: Fanuc/Siemens/Heidenhain后处理器参数硬编码在代码中，修改配置需要改代码并重新部署。

**修复**: 新增`config_loader.py`配置加载器，YAML配置+深度合并+缓存管理(TTL 300s)，支持运行时配置更新。

**影响范围**: `python/app/postprocessor/config_loader.py`, `config/postprocessor_config.yaml`

### 3.6 数据库迁移手动管理

**问题**: 数据库Schema变更依赖手动SQL脚本，无版本管理，不支持回滚。

**修复**: 引入Alembic迁移系统，版本化Schema管理，`alembic upgrade/downgrade`支持前向/后向迁移。

**影响范围**: `python/alembic/`目录

### 3.7 审计日志格式不统一

**问题**: 审计日志格式分散，难以查询和分析。

**修复**: 统一为结构化格式，支持按模块/决策/时间范围过滤，JSON导出。

**影响范围**: `python/app/core/audit_log.py`, `src/composables/useAuditLog.ts`

## 四、性能优化

### 4.1 统一认证中间件短路优化

公开路径在ASGI层早期短路，零认证开销。纯ASGI实现不缓存body，内存占用显著降低，高并发场景性能提升明显。

**影响范围**: `python/app/core/middleware/unified_auth.py`

### 4.2 LNN GPU训练加速

PyTorch实现支持GPU训练，AMP混合精度减少显存占用，自动批大小优化根据显存动态调整（≥16GB→4x）。CFC模型无需ODE求解器，比LSTM快160x。

**影响范围**: `python/app/ai/lnn/models/torch_*.py`, `python/app/ai/lnn/training/`

### 4.3 INT8量化推理加速

动态/静态量化将模型压缩约4x，推理速度显著提升，适合边缘设备部署。

**影响范围**: `python/app/ai/lnn/quantization/quantizer.py`

### 4.4 体素仿真向量化

numpy向量化操作替代Python循环，稀疏体素更新+AABB预过滤跳过远距离刀位点，仿真性能大幅提升。

**影响范围**: `python/app/simulation/voxel_cutter.py`

### 4.5 Rust计算模块预研

Rust原生体素化/碰撞检测/刀路解析预期性能提升50-100x（体素化）和10-20x（G代码解析），通过PyO3零拷贝NumPy传递。

**影响范围**: `src-tauri/src/compute/`

### 4.6 后处理配置缓存

YAML配置加载后缓存300s，避免重复文件读取和解析开销。

**影响范围**: `python/app/postprocessor/config_loader.py`

### 4.7 数据集两级缓存

内存缓存(1GB) + 磁盘缓存(5GB)，MD5缓存键+LRU淘汰，训练启动加速显著。

**影响范围**: `python/app/ai/lnn/training/dataset_cache.py`
