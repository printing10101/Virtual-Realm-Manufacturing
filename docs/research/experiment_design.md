## 一、实验总体框架

### 1.1 实验目标

验证 CT-LTC 方法在铣削颤振稳定性预测任务上的有效性，具体包括：

1. **主实验**: 在 5 个数据集上与 8 种基线方法对比，验证预测精度优势
2. **跨工况泛化实验**: 通过 LOMO/LOCO 协议验证泛化能力
3. **消融实验**: 量化各核心组件（PCC Loss、两阶段训练、LTC架构、门控融合）的贡献
4. **物理一致性分析**: 验证预测 SLD 与解析 SLD 的物理一致性
5. **工业案例研究**: 在自采 6061-T6 数据集上验证实际应用能力

## 二、数据集设计

### 2.1 合成数据集 (Synthetic)

**用途**: 阶段一解析预训练

**生成方法**:
- 使用 Tlusty 解析公式: `a_lim = -1 / (2·Kₛ·Re[G(jω)])`
- 参数空间:
  - 主轴转速 n: [1000, 10000] rpm (100个均匀采样点)
  - 轴向切深 a: [0.1, 10.0] mm (100个均匀采样点)
  - 机床参数: k=1e6 N/m, m=100 kg, ζ=0.05
  - 切削力系数: Kₛ=2000 N/mm²
- 总样本数: 10,000 组

**数据格式**:
```python
{
    'input': {
        'spindle_speed': float,  # 主轴转速 (rpm)
        'axial_depth': float,    # 轴向切深 (mm)
        'material_id': int,      # 材料ID
        'tool_id': int           # 刀具ID
    },
    'output': {
        'stability_label': int,  # 0=稳定, 1=不稳定
        'limiting_depth': float  # 极限切深 (mm)
    },
    'physics_output': {
        'tlusty_prediction': float  # Tlusty公式预测值
    }
}
```

## 三、模型实现

### 3.1 CT-LTC 模型 (本文方法)

**架构**:
```
输入 (2维: 主轴转速, 轴向切深)
  ↓
输入编码层 (Linear: 2 → 64)
  ↓
LTC 数据驱动分支 (3层堆叠, hidden_dim=64)
  ├─ LTC Cell 1 (τ₁ 可学习)
  ├─ LTC Cell 2 (τ₂ 可学习)
  └─ LTC Cell 3 (τ₃ 可学习)
  ↓
ŷ_data (极限切深预测)
  ↓
门控融合层 (α·ŷ_data + (1-α)·ŷ_physics)
  ↓
最终输出 ŷ = a_lim
```

**关键参数**:
- `ltc_hidden_dim`: 64
- `ltc_num_layers`: 3
- `ltc_dt`: 0.1 (时间步长)
- `ltc_tau_init`: 0.1 (时间常数初始值)
- `dropout`: 0.2

**LTC Cell 实现**:
```python
class LTCCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.W = nn.Parameter(torch.randn(hidden_size, input_size))
        self.U = nn.Parameter(torch.randn(hidden_size, hidden_size))
        self.bias = nn.Parameter(torch.zeros(hidden_size))
        self.tau = nn.Parameter(torch.ones(hidden_size) * 0.1)  # 可学习时间常数
        
    def forward(self, x, h, dt=0.1):
        tau = torch.clamp(self.tau, min=0.01)
        dh = torch.tanh(torch.mm(x, self.W.t()) + torch.mm(h, self.U.t()) + self.bias)
        h_new = h + dt * (dh - h) / tau.unsqueeze(0)
        return h_new
```

## 四、损失函数设计

### 4.1 PCC Loss (Physics-Consistency Loss)

**总损失**:
```
L_total = λ₁·L_data + λ₂·L_phys + λ₃·L_pcc
```

**各组件**:

#### (1) 数据损失 L_data
```python
L_data = mean(|y_pred - y_true|)  # MAE
```

#### (2) 物理损失 L_phys (数值层)
```python
L_phys = mean(max(0, |y_pred - y_physics| - ε_phys))
# ε_phys = 0.05 mm
```

#### (3) 梯度一致性损失 L_pcc (梯度层)
```python
grad_pred = torch.autograd.grad(y_pred.sum(), x, create_graph=True)[0]
grad_physics = torch.autograd.grad(y_physics.sum(), x, create_graph=True)[0]
L_pcc = mean(|grad_pred - grad_physics|)
```

**权重设置**:
- `λ₁ = 1.0` (数据损失)
- `λ₂ = 0.5` (物理损失)
- `λ₃ = 0.1` (梯度损失)
- `ε_phys = 0.05 mm` (物理阈值)

## 五、训练策略

### 5.1 阶段一: 解析预训练

**目标**: 使网络先收敛到"物理可行域"

**配置**:
- **数据集**: 合成数据集 (10,000 组)
- **损失函数**: 仅 L_data (MAE)
- **Epochs**: 100
- **学习率**: 3e-4 → 1e-5 (余弦退火)
- **Batch size**: 32
- **优化器**: AdamW (weight_decay=1e-5)

### 5.2 阶段二: 物理残差微调

**目标**: 在真实数据上微调，叠加物理约束

**配置**:
- **数据集**: 真实数据集 (PHM2010/NUAA/NIST/ACADEMIC/INDUSTRIAL)
- **损失函数**: L_total = λ₁·L_data + λ₂·L_phys + λ₃·L_pcc
- **Epochs**: 200
- **学习率**: 3e-4 → 1e-5 (余弦退火)
- **Batch size**: 32
- **优化器**: AdamW (weight_decay=1e-5)
- **早停**: patience=20, monitor=val_loss

## 十、风险与应对

### 风险 1: 公开数据集获取困难

**应对**:
- 优先使用 PHM2010 (最易获取)
- 若其他数据集无法获取，可用合成数据替代
- 增加自采工业数据比重

### 风险 2: CT-LTC 训练不收敛

**应对**:
- 调整学习率 (降低至 1e-4)
- 增加预训练 epoch (200 → 300)
- 使用梯度裁剪 (max_norm=1.0)

### 风险 3: 物理约束过强导致性能下降

**应对**:
- 调整 λ₂, λ₃ 权重 (降低至 0.3, 0.05)
- 增大 ε_phys 阈值 (0.05 → 0.1 mm)
- 使用渐进式物理约束 (前 50 epoch 不使用物理损失)

### 风险 4: 实验结果不如预期

**应对**:
- 分析失败案例，调整模型结构
- 增加数据增强 (噪声注入、数据插值)
- 尝试其他连续时间模型 (Neural ODE, RNN-ODE)
