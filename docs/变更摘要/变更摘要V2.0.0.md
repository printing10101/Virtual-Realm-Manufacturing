## 一、版本概述

V2.0.0 是灵境制造从"V1.x 单体研发线"跨入"**V2 工业化生产基线**"的**重大里程碑版本**。本版本以"**桌面端原生化、AI 引擎工业化、工艺规划闭环、跨语言计算下沉**"为四大主线，将 V1.12.x 暂存区中累计超过 1700 个新文件一次性集成到主干，标志着项目进入"**可对外交付的工业化阶段**"。

V2.0.0 是一次**结构性重构 + 功能完整性补齐**的版本，包含：

- **桌面端 Tauri 2.0 框架落地**：从纯 Web 应用升级为原生桌面应用
- **Rust 计算模块下沉**：通过 PyO3 将高性能核心计算下沉到 Rust
- **AI 引擎体系化**：LNN 推理、IJEPA 3D、跨层融合、Unified Embedding 形成完整工具链
- **工艺规划闭环**：从特征识别到 NC 代码后处理全链路打通
- **统一鉴权 + 预算治理**：构建可审计、可治理的多租户运行底座
- **插件 / 模板市场**：支持第三方能力扩展
- **测试与文档工业化**：E2E、基准测试、可视化报告、Wiki 知识库全部补齐

**V2.0.0 核心亮点**：

- 桌面端基于 Tauri 2.0 + Vue 3 + Pinia + Element Plus 的现代化技术栈
- 后端基于 FastAPI + Rust(PyO3) 的混合计算架构
- LNN 推理引擎：cfc / ltc / hybrid / quantization 全套模型族
- IJEPA 3D + Unified Embedding：跨模态几何表征
- 工艺规划：特征识别 → 工序编排 → 刀轨规划 → 后处理 → 仿真 全链路闭环
- 端到端测试覆盖：单元 / 集成 / E2E / 性能基准 / 安全 / 兼容性 6 套测试体系
- 文档体系：综合文档 + Wiki + API 自动同步 + 变更摘要 4 层文档治理

> **重要提示**：V2.0.0 为**主版本号变更**，包含破坏性 API 变更、架构升级与数据模型调整。请阅读「[兼容性说明](#十二兼容性说明)」章节评估升级风险。

## 二、重大架构升级

### 2.1 桌面端 Tauri 2.0 框架落地

**重要性**: ⭐⭐⭐⭐⭐ **架构级**

**变更内容**：

新增 `src-tauri/` 模块，基于 **Tauri 2.0** 构建原生桌面端运行时，将 Web 前端与本地后端服务（Python Sidecar）整合为单一可执行文件。

**新增文件**：

| 文件 | 作用 |
|------|------|
| `src-tauri/Cargo.toml` | Rust 依赖清单与构建配置 |
| `src-tauri/tauri.conf.json` | Tauri 应用配置（窗口、权限、Sidecar 绑定） |
| `src-tauri/build.rs` | 构建脚本 |
| `src-tauri/src/main.rs` | 应用入口 |
| `src-tauri/src/lib.rs` | 库入口与模块组织 |
| `src-tauri/src/commands.rs` | Tauri 命令（前端 ↔ Rust IPC） |
| `src-tauri/src/sidecar.rs` | Python Sidecar 生命周期管理（启动 / 停止 / 健康检查） |
| `src-tauri/capabilities/default.json` | 能力声明（文件系统、网络、Shell） |
| `src-tauri/icons/README.md` | 图标资源说明 |

**关键技术点**：

- **Sidecar 模式**：Python 后端作为子进程由 Tauri 托管，前端通过 `invoke` 调用后端
- **能力声明**：`capabilities/default.json` 显式声明前端可访问的 Rust API，最小权限原则
- **前端 ↔ Rust IPC**：`commands.rs` 中实现 `get_version_info` 等系统级命令

### 2.2 Rust 计算模块（PyO3 绑定）

**重要性**: ⭐⭐⭐⭐⭐ **架构级**

**变更内容**：

新增 `src/compute/` Rust 核心计算模块，通过 **PyO3** 暴露给 Python 后端，实现"**核心计算下沉到 Rust，热路径性能提升 5-10x**"。

**模块结构**：

```
src/compute/
├── Cargo.toml                          # 根 Cargo 工作空间
├── pyproject.toml                      # Python 端 maturin 打包
├── crates/
│   ├── core/
│   │   ├── Cargo.toml
│   │   ├── benches/cutting_bench.rs    # 切削仿真基准
│   │   └── src/
│   │       ├── lib.rs                  # 模块入口
│   │       ├── error.rs                # 错误类型
│   │       ├── tool.rs                 # 刀具几何
│   │       ├── voxel_grid.rs           # 体素栅格（DDA 求交）
│   │       └── cutting.rs              # 切削求交核心
│   └── pyo3_bindings/
│       ├── Cargo.toml
│       └── src/lib.rs                  # PyO3 绑定
```

**关键算法**：

- **Voxel Grid 切削求交**：基于 DDA（Digital Differential Analyzer）算法，体素空间下快速判定材料去除量
- **刀具几何建模**：支持圆柱、圆锥、球头、平底等多种刀具类型
- **PyO3 绑定**：Rust 函数以原生 Python 模块形式暴露，零拷贝数据传递

**配套集成**：

- `python/app/simulation/rust_engine.py`：Python 端 Rust 引擎绑定
- `python/app/simulation/voxel_cutter.py`：体素切削实现
- `python/scripts/run_voxel_benchmark.py`：基准测试脚本

### 2.3 前端技术栈全面升级

**重要性**: ⭐⭐⭐⭐ **架构级**

**变更内容**：

前端从 V1.x 升级为现代化的 **Vue 3 + TypeScript + Vite + Pinia + Element Plus** 栈。

**技术选型**：

### 12.1 主版本号变更（Breaking Changes）

V2.0.0 是**主版本号变更**，包含以下破坏性变更：

| 变更项 | 影响范围 | 迁移建议 |
|--------|----------|----------|
| 前端技术栈 | 旧版 Vue 2 组件无法直接使用 | 全部使用 Vue 3 + `<script setup>` |
| Tauri 桌面端 | 命令格式与旧版不同 | 升级 `tauri.conf.json` 能力声明 |
| API 鉴权 | Token 格式升级 | 旧 Token 需重新签发 |
| 数据库 | Alembic 迁移链变更 | 升级前必须执行 `alembic upgrade head` |
| LNN 模型 | 旧模型权重不兼容 | 重新训练 / 重新量化 |
| 配置格式 | YAML 配置结构调整 | 使用 `scripts/setup_hooks.py` 迁移 |
| 插件协议 | 旧插件需重写 | 参考新插件开发指南 |

### 12.2 部署注意事项

- **Python 依赖**：V2.0.0 新增 PyO3 绑定，需 Rust 工具链（`rustc >= 1.70`）用于 `maturin develop`
- **Node 依赖**：前端要求 `Node.js >= 18` + `pnpm >= 8`
- **环境变量**：
  - `LNN_DATA_DIR` / `LNN_OUTPUT_DIR` / `LNN_UPLOAD_DIR`（继承自 V1.12.1，路径白名单）
  - `APP_VERSION`（Python 配置默认 "2.0.0"）
- **数据库迁移**：V1.12.1 → V2.0.0 需执行 `alembic upgrade head`
- **Sidecar 启动**：Tauri 启动时自动拉起 Python 子进程，需在 `capabilities/default.json` 中声明 `shell:allow-execute`

### 12.3 客户端适配

- **桌面端用户**：重新下载 `lingjing-setup-v2.0.0.exe` 安装包
- **容器化部署**：`docker pull lingjing/manufacturing-api:2.0.0`
- **源码安装**：`git clone --branch v2.0.0` 或更新 `git pull` 后执行 `pnpm install` + 重新构建 Sidecar

### 12.4 第三方插件与模板

- 旧插件需要按新协议重写（参考 `tools/plugin-cli.py`）
