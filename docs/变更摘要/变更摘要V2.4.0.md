## 五、安全加固

### 5.1 路径遍历漏洞修复
- **文件**: `python/app/utils/utils.py`
- **修复**: 使用 `is_relative_to` 替代字符串前缀匹配
- **新增函数**:

  - `validate_user_path()` - 统一路径校验工厂函数

### 5.2 Docker 安全配置
- **文件**: `docker-compose.yml`
- **安全修复 [B36]**:
  - API(8765)、Prometheus(9090)、Grafana(3000) 端口绑定至 `127.0.0.1`
  - 环境变量强制必填：Redis/Postgres/Grafana 密码使用 `${VAR:?error}` 语法
  - 镜像源可配置：从硬编码阿里云改为 `${IMAGE_REGISTRY:-docker.io}`
- **环境变量重命名**: `DB_URL` → `DATABASE_URL`

### 5.3 JWT 安全修复
- **文件**: `requirements.txt`
- **修复**: `python-jose` 3.3.0 → 3.4.0（修复 CVE-2024-33664 算法混淆漏洞）
- **移除**: `passlib`（bcrypt 4.x 已原生支持，无需兼容层）

### 5.4 CI/CD 安全加固
- **文件**: `.github/workflows/ci.yml`, `.github/workflows/post-merge.yml`
- **改进**:
  - 类型检查失败将真正阻断流水线（移除 `|| true`）
  - 集成测试失败将真正阻断流水线（移除 `|| echo "部分集成测试失败（非阻塞）"`）
  - 版本一致性检查脚本从 `version-sync.js` 改为 `version-sync.cjs`

### 5.5 异常处理规范化
- **移除**: `python/app/core/silently_swallow.py` - 静默异常处理
- **改进**: 使用 `extractErrorMessage` 替代静默 catch
