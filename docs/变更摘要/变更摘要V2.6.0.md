## 一、版本概述

V2.6.0 是灵境制造系统的架构演进版本，核心聚焦于**前后端契约层建设**、**共享模块抽取**、**数据飞轮插件系统**以及**论文实验脚本支持**。本版本新增超过 300 个单元测试，前端测试覆盖率显著提升，同时建立了工程与研究模块的解耦基础。

**核心统计**:

| 变更文件数 | 450+ |
| 新增文件 | 280+ |
| 删除文件 | 120+ |

| 新增契约定义 | 13 个 |

| 新增前端 View | 6 个 |

## 二、主要功能变更

### 2.1 共享契约层建设（shared/）

**背景**: 为解决工程模块与研究模块之间的数据契约不一致问题，本版本抽取了共享契约层，建立统一的数据类型定义和协议规范。

**新增模块**:
- `shared/constants/`: 常量定义（材料参数、精度阈值、门控条件）
- `shared/data/`: 数据契约（contracts.py、dataset.py）
- `shared/lnn/`: LNN 模型相关类型定义（types.py、protocols.py、artifact.py、model_card.py）

**关键文件**:
- `shared/pyproject.toml`: 共享模块包配置
- `shared/README.md`: 模块使用说明

**影响范围**: 为后续工程与研究模块解耦奠定基础，当前已通过 `.pth` 文件方式集成到工程虚拟环境。

## 三、API 接口调整

### 3.1 新增 API 路由

**CAM 验证相关**:
- `POST /api/v1/cam-validation/validate-gcode`: G-code 验证
- `GET /api/v1/cam-validation/adapters`: 获取可用 CAM 适配器列表

**数据飞轮相关**:
- `POST /api/v1/flywheel/feedback`: 提交反馈
- `GET /api/v1/flywheel/metrics`: 获取飞轮指标
- `POST /api/v1/flywheel/hot-update`: 触发模型热更新

**图像到 3D 重建相关**:
- `POST /api/v1/image-to-3d/reconstruct`: 图像重建 3D 模型
- `GET /api/v1/image-to-3d/status/{task_id}`: 查询重建状态

### 3.2 API 契约一致性检查

**新增脚本**: `scripts/check_response_model.py`

**功能**: 自动检查 API 响应模型与契约定义的一致性，防止接口文档与实现不符。

## 六、已知问题及修复

### 6.1 已修复问题

**WinSock 初始化问题**:
- **问题**: Windows 平台下某些网络操作可能因 WinSock 未正确初始化而失败
- **修复**: 新增 `python/scripts/diagnose_winsock.ps1`、`python/scripts/run_winsock_reset.ps1`、`python/scripts/winsock_reset_admin.bat` 等诊断和修复脚本
- **相关文件**: `python/scripts/test_winhttp_connectivity.ps1`

**PyTorch 依赖问题**:
- **问题**: 某些环境下载 PyTorch 困难
- **修复**: 新增 `python/scripts/download_torch_via_winhttp.ps1` 提供备用下载方案
- **验证**: `python/scripts/verify_torch_ready.py` 验证 PyTorch 环境

**WPS 自动更新干扰实验**:
- **问题**: WPS 自动更新可能中断夜间实验
- **修复**: `论文相关/脚本/guard_wps_update.py` 守护脚本，自动禁用 WPS 更新

### 6.2 已知限制

**共享模块加载**:
- **问题**: 当前共享模块通过 `.pth` 文件方式加载，不够优雅
- **计划**: 后续版本将改为正式的 Python 包安装方式

**CAM 适配器依赖**:
- **问题**: CAM 适配器需要对应 CAM 软件已安装并正确配置
- **说明**: 这是预期行为，系统无法替代 CAM 软件本身
