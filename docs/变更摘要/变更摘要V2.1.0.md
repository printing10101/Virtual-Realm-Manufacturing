## 一、主要功能变更说明

### 1.1 AI 推理引擎增强

#### 1.1.1 贝叶斯 LNN 模型（新增）
- **文件**: `python/app/ai/lnn/models/bayesian_lnn.py`
- **功能**: 实现基于 MC Dropout 的贝叶斯液态神经网络模型
- **特性**:
  - 支持不确定性量化（Uncertainty Quantification）
  - 通过多次前向传播估计预测方差
  - 封装现有 CFCModel，注入额外 Dropout 层
  - 提供 `predict_with_uncertainty()` API，同时返回均值和标准差
- **应用场景**: 需要置信度评估的关键决策场景

#### 1.1.2 主动学习触发系统（新增）
- **文件**: `python/app/ai/active_learning/triggers.py`
- **功能**: 实现 5 类独立的触发场景检测器
- **触发器类型**:
  1. **低置信度触发器** (LowConfidenceTrigger): 检测模型预测不确定性过高
  2. **知识缺失触发器** (KnowledgeGapTrigger): 识别训练数据覆盖不足的领域
  3. **证据冲突触发器** (ConflictingEvidenceTrigger): 检测相互矛盾的输入特征
  4. **新颖情境触发器** (NovelSituationTrigger): 识别分布外（OOD）样本
  5. **关键决策触发器** (CriticalDecisionTrigger): 标记高风险决策点
- **输出**: 标准化事件对象，包含触发原因、上下文信息、优先级

#### 1.1.3 自动重训练管道（新增）
- **模块**: `python/app/ai/auto_retrain/`
- **组件**:
  - `data_prep.py`: 训练数据准备与清洗
  - `evaluator.py`: 模型性能评估与对比
  - `scheduler.py`: 重训练任务调度
- **特性**:
  - 基于主动学习事件触发重训练
  - 自动化数据质量检查
  - 模型版本管理与性能对比

#### 1.1.4 贝叶斯预测器（新增）
- **文件**: `python/app/ai/lnn/inference/bayesian_predictor.py`
- **功能**: 封装贝叶斯 LNN 模型的推理逻辑
- **特性**:
  - MC Dropout 推理（保持 Dropout 层激活）
  - 多次采样聚合预测结果
  - 输出预测分布（均值 + 不确定性）

### 1.2 工业协议集成

## 五、已知问题

### 5.1 贝叶斯 LNN 性能
- **问题**: MC Dropout 推理需要多次前向传播，推理时间较长
- **缓解措施**: 
  - 默认采样次数设置为 50（可配置）
  - 建议使用 GPU 加速
  - 后续版本将优化推理速度

### 5.2 知识图谱规模限制
- **问题**: 当前使用 NetworkX 内存图，节点数超过 100 万时内存占用较高
- **缓解措施**:
  - 建议节点数控制在 50 万以内
  - 后续版本将支持分布式图存储

### 5.3 MTConnect 协议版本
- **问题**: 部分旧版 MTConnect Agent 可能存在兼容性问题
- **缓解措施**:
  - 已测试 MTConnect 1.5+ 版本
  - 提供协议版本检测与错误提示
  - 建议升级到最新版本
