## 3. 核心开发流程

### 3.1 添加新模型

**步骤 1：创建模型类**

```python
# python/app/ai/lnn/models/my_model.py
from app.ai.lnn.models.torch_base_lnn import BaseLNN, LNNConfig
import torch
import torch.nn as nn

class MyModel(BaseLNN):
    """自定义LNN模型"""
    
    def __init__(self, config: LNNConfig):
        super().__init__(config)
        self.layer = nn.Linear(config.input_size, config.hidden_size)
    
    def forward(self, x: torch.Tensor, dt: float = 0.1):
        """前向传播"""
        if self.hidden_state is None or self.hidden_state.shape[0] != x.shape[0]:
            self.hidden_state = self.init_hidden(x.shape[0])
        
        h = torch.tanh(self.layer(x))
        self.hidden_state = h
        out = self.output_layer(h)
        return out, self.hidden_state
```

**步骤 2：注册模型**

```python
from app.ai.lnn.inference.registry import ModelRegistry

registry = ModelRegistry()
registry.register_custom_model(
    model_name="my_model",
    model_class=MyModel,
    input_dim=10,
    output_dim=1,
)
```

## 4. 模型训练最佳实践

### 4.1 数据准备

```python
from app.ai.lnn.training.bosch_dataset import BoschDatasetProcessor, BoschDataConfig

config = BoschDataConfig(
    target_columns=["cutting_force"],
    test_size=0.2,
    val_size=0.1,
    normalization_method="standard",
    batch_size=64,
)

processor = BoschDatasetProcessor(config)
processor.load_data("data/my_dataset.csv")
processor.clean_data()
processor.engineer_features(
    add_lag_features=True,
    lag_steps=[1, 3, 5],
    add_rolling_stats=True,
    rolling_windows=[5, 10],
)

train_loader, val_loader, test_loader = processor.create_dataloaders()
```

### 4.2 训练配置

```python
from app.ai.lnn.training.trainer import LNNTrainer

trainer = LNNTrainer(
    model=model,
    learning_rate=0.001,
    optimizer_type="adam",
    loss_type="mse",
    batch_size=64,
    epochs=100,
    device="cuda",
    early_stopping_patience=15,  # 早停耐心值
    gradient_clip_val=1.0,       # 梯度裁剪
    use_amp=True,               # 混合精度训练
)
```

### 5.3 常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| CUDA OOM | batch_size过大 | 减小batch_size或启用梯度检查点 |
| 训练不收敛 | 学习率过高 | 降低学习率或使用学习率调度 |
| 推理延迟高 | 模型过大 | 使用CFC模型或导出TorchScript |
| 内存泄漏 | 未清理缓存 | 使用`MemoryOptimizer.optimize_memory()` |
