## 一、硬件环境分析

### 1.1 目标硬件平台

| 硬件维度 | 最低配置 | 推荐配置 | 说明 |
|---------|---------|---------|------|
| **CPU** | x86_64 4 核 | x86_64 8 核+ | AI 推理密集，多核有益 |
| **内存** | 8 GB | 16 GB+ | Ollama 7B 模型需 ~4GB |
| **存储** | 10 GB SSD | 20 GB NVMe SSD | 模型 + 依赖 + 生成文件 |

| **显卡** | 支持 WebGL 2.0 | 支持 Vulkan | Three.js 3D 渲染 |
| **网络** | 无（本地模式） | 10 Mbps+ | 云端 API / 自动更新 |

## 三、进程与内存管理

### 3.1 进程生命周期管理

```
启动流程:
1. Tauri 主进程启动
2. 创建应用数据目录
3. 初始化 JSON 文件存储（Repository 模式）
4. 启动 WebView2 渲染进程
5. (可选) 启动 Python Sidecar
6. (可选) 启动 Ollama

关闭流程:
1. 保存所有未保存数据
2. 停止 Python Sidecar
3. (可选) 停止 Ollama
4. 关闭文件系统连接
5. 关闭 WebView2
6. 退出主进程
```

#### 3.2.2 Three.js 内存管理

```typescript
// 组件卸载时完整释放资源
onUnmounted(() => {
  // 1. 停止动画循环
  if (animationId) cancelAnimationFrame(animationId)
  
  // 2. 释放模型 geometry 和 material
  if (modelMesh) {
    modelMesh.traverse((child) => {
      if (child instanceof THREE.Mesh) {
        child.geometry?.dispose()
        if (Array.isArray(child.material)) {
          child.material.forEach(m => m.dispose())
        } else {
          child.material?.dispose()
        }
      }
    })
    scene.remove(modelMesh)
  }
  
  // 3. 释放 WebGL 上下文
  if (renderer) {
    renderer.dispose()
    renderer.forceContextLoss()
    if (renderer.domElement.parentNode) {
      renderer.domElement.parentNode.removeChild(renderer.domElement)
    }
  }
  
  // 4. 移除事件监听
  window.removeEventListener('resize', onWindowResize)
})
```

#### 4.2.2 数据仓储层（Repository Pattern）

```
Repository 抽象层:
├── base.py - 定义仓储通用接口
├── json_repository.py - JSON 文件仓储实现
├── chroma_repository.py - ChromaDB 向量数据仓储
├── file_repository.py - 文件系统仓储
└── factory.py - 根据配置创建相应仓储实例
```

**优势**: 
- 统一数据访问接口，易于替换底层存储
- Python 层仓储模式，避免 Rust 层直接操作文件系统
- 支持多种存储后端（JSON、ChromaDB、文件）

#### 4.2.3 JSON → 新格式迁移流程

```
数据迁移/备份流程:
1. 应用启动时检测数据文件格式
2. 如果存在旧版 .json.bak 文件，读取旧数据
3. 验证数据完整性
4. 转换为新版 JSON 格式
5. 写入成功，保留旧文件作为备份
6. 后续操作使用新格式
7. 异常时降级读取备份文件
```

#### 4.2.4 并发控制

```
JSON 文件访问:
├── 读操作: 可并发（文件锁共享模式）
├── 写操作: 串行（独占文件锁）
└── 优化方案: 内存缓存 + 异步刷盘
```

fn is_process_alive(pid: u32) -> bool {
    #[cfg(windows)]
    {
        // Windows: 使用 tasklist
        let output = Command::new("tasklist")
            .args(["/FI", &format!("PID eq {}", pid), "/NH"])
            .output();
        // ...
    }
    
    #[cfg(unix)]
    {
        // Unix: 使用 kill -0
        Command::new("kill")
            .args(["-0", &pid.to_string()])
            .output()
            .map(|o| o.status.success())
            .unwrap_or(false)
    }
}
