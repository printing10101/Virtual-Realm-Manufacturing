## 一、系统架构总览

### 1.1 架构模式

灵境制造采用**桌面应用 + Sidecar 微服务**架构：

```
┌─────────────────────────────────────────────────┐
│                  Tauri 2 桌面应用                │
│  ┌───────────────────────────────────────────┐  │
│  │  Vue 3 前端 (WebView2)                    │  │
│  │  ├── Three.js 3D 渲染                    │  │
│  │  ├── Element Plus UI                     │  │
│  │  └── Pinia 状态管理                      │  │
│  └───────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────┐  │
│  │  Rust 后端 (Tauri Core)                   │  │
│  │  ├── 文件系统操作                         │  │
│  │  ├── 进程管理 (健康检查)                   │  │
│  │  ├── HTTP 代理 (reqwest)                  │  │
│  │  └── JSON 持久化                          │  │
│  └───────────────────────────────────────────┘  │
├─────────────────────────────────────────────────┤
│                  Python Sidecar                 │
│  ┌───────────────────────────────────────────┐  │
│  │  FastAPI Web Server                      │  │
│  │  ├── LNN 引擎 (CFC/LTC/Hybrid)           │  │
│  │  ├── 模型注册系统                         │  │
│  │  ├── LNN 训练器                           │  │
│  │  ├── Uniwear 数据集处理                    │  │
│  │  └── Prometheus 指标监控                   │  │
│  └───────────────────────────────────────────┘  │
├─────────────────────────────────────────────────┤
│                  Ollama (可选)                   │
│  ┌───────────────────────────────────────────┐  │
│  │  本地 LLM 推理服务                         │  │
│  └───────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

### 1.2 技术栈

| 层级 | 技术 | 版本 | 职责 |
|------|------|------|------|
| 表示层 | Vue 3 + TypeScript | 3.4+ / 5.3+ | UI 渲染、用户交互 |
| 3D 渲染 | Three.js | 0.170+ | WebGL 模型查看 |
| 桌面层 | Tauri 2 + Rust | 2.x / 2021 | 系统级操作、进程管理 |
| AI 服务层 | Python + FastAPI | 3.11 / 0.110+ | LNN 推理、训练、评估 |
| 深度学习 | PyTorch | 2.1+ | LNN 模型训练和推理 |
| LLM 层 | Ollama | latest | 本地 LLM 推理（可选） |

## 五、LNN 模型架构

### 5.1 LNN 概述

**LNN（Logical Neural Network，神经逻辑网络）** 是本项目核心 AI 引擎，结合了神经网络的可学习性和逻辑规则的可解释性。

### 5.2 模型类型

| 模型类型 | 文件 | 特点 | 适用场景 |
|---------|------|------|---------|
| CFC | `cfc_model.py` | 连续时间动态，基于 ODE | 切削参数预测 |
| LTC | `ltc_model.py` | 液体时间常数，自适应 | 刀具磨损预测 |
| HybridLNN | `hybrid_lnn.py` | 混合架构，多模型融合 | 复杂工艺规划 |
| ParameterModels | `parameter_models.py` | 轻量参数模型 | 快速推理 |

### 5.3 模型注册系统

**文件**: `python/app/ai/lnn/inference/registry.py`

```python
class LNNModelRegistry:
```

**功能**: 统一管理所有 LNN 模型的注册、加载、验证和访问。

## 六、通信架构

### 6.1 通信链路

```
前端 (Vue) 
    │ ← Tauri invoke() / HTTP 请求
    ↓
Rust (Tauri Core)
    │ ← HTTP 代理
    ↓
Python (FastAPI)
    │ ← HTTP 请求
    ↓
LNN 引擎 / Ollama (LLM)
```

### 6.2 延迟分析

| 通信路径            | 延迟             | 说明             |
| --------------- | -------------- | -------------- |
| 前端 → Tauri      | ~1ms          | IPC 序列化开销      |
| Tauri → Python  | ~5-20ms       | HTTP 请求 + 反序列化 |
| Python → LNN   | ~1-50ms       | LNN 推理（视模型大小）  |
| **全链路**         | **~7-71ms** | 累积延迟           |

### 6.3 HTTP 代理

**文件**: `src-tauri/src/commands/proxy.rs`

Rust 层提供 HTTP 代理模块：
- `proxy_http_request` - 单个 HTTP 请求代理
- `proxy_batch_request` - 批量 HTTP 请求代理
- `proxy_health_check` - 健康检查代理

使用 `reqwest` 库实现，支持连接复用和错误重试。

## 八、数据架构

### 8.1 数据存储

| 数据类型  | 存储位置                    | 存储方式               | 说明          |
| ----- | ----------------------- | ------------------ | ----------- |
| 应用设置  | JSON 文件                 | serde_json / json | Rust/Python 层 |

| 模型权重 | 本地文件系统                  | PyTorch .pt 文件    | 按模型名称命名   |

| 数据集  | CSV/HDF5 文件            | python/data/       | Uniwear/PHM2010 |

### 8.2 数据流

#### LNN 推理流程

```
用户输入（切削参数/特征数据）
    │
    ├── 数据预处理（标准化、特征提取）
    │
    ├── 模型选择（CFC/LTC/HybridLNN）
    │   │
    │   ├── 从注册表获取模型
    │   ├── 加载模型权重
    │   └── 执行推理
    │
    ├── AMP 推理（如支持）
    │
    └── 后处理（置信度计算、结果格式化）
        │
        └── 返回预测结果
```

#### LNN 训练流程

```
准备数据集（CSV/HDF5）
    │
    ├── 数据加载和预处理
    │
    ├── 划分训练集/验证集（80/20）
    │
    ├── 创建 DataLoader
    │
    ├── 初始化 LNNTrainer
    │
    ├── 训练循环（多轮 epoch）
    │   ├── 前向传播
    │   ├── 损失计算（MSE）
    │   ├── 反向传播
    │   └── 优化器更新
    │
    └── 保存训练结果和指标
```
