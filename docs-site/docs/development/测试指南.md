# 测试指南

> 本文给出**测试策略、测试环境配置、各类测试执行方法、覆盖率要求与报告生成**的完整说明。
> 适用版本：v2.0.0

## 1. 测试策略总览

```
              ┌─────────────────────────────────────┐
              │              系统层 (E2E)             │
              │   Playwright + 真实服务 + 真实数据    │
              │   覆盖：完整用户旅程、跨服务集成        │
              └──────────────┬──────────────────────┘
                             │
              ┌──────────────┴──────────────────────┐
              │              集成层 (Integration)     │
              │   pytest + TestClient + Testcontainers│
              │   覆盖：API 路由、DB 交互、SSE、缓存   │
              └──────────────┬──────────────────────┘
                             │
              ┌──────────────┴──────────────────────┐
              │              单元层 (Unit)            │
              │   pytest / Vitest                    │
              │   覆盖：纯函数、类方法、组件 props     │
              └─────────────────────────────────────┘
```

### 1.1 测试金字塔

| 层级 | 工具 | 数量目标 | 单测时长 |
|------|------|----------|----------|
| 单元 | pytest / Vitest | 70% | < 100 ms / case |
| 集成 | pytest + httpx | 20% | < 5 s / case |
| E2E | Playwright | 10% | < 60 s / case |

### 1.2 测试原则

1. **FIRST**：Fast、Independent、Repeatable、Self-validating、Timely
2. **AAA 模式**：Arrange → Act → Assert
3. **测试金字塔**：不要为 UI 写大量 E2E
4. **确定性**：禁止依赖时间、网络、随机（必须 mock）
5. **可读性**：测试名即文档（`test_<unit>_<scenario>_<expected>`）

#### 示例：测试 DXF 解析器

```python
# python/app/dxf/tests/test_parser.py
import pytest
from app.dxf.parser import DxfParser

@pytest.fixture
def sample_dxf_path(tmp_path):
    p = tmp_path / "sample.dxf"
    p.write_bytes(MINIMAL_DXF_BYTES)  # 测试夹具
    return p

def test_dxf_parser_extracts_entities(sample_dxf_path):
    # Arrange
    parser = DxfParser()
    
    # Act
    result = parser.parse(sample_dxf_path)
    
    # Assert
    assert result.entities.line_count == 12
    assert result.entities.circle_count == 3
    assert result.units == "mm"

def test_dxf_parser_rejects_invalid_file(tmp_path):
    p = tmp_path / "bad.dxf"
    p.write_text("not a dxf")
    parser = DxfParser()
    
    with pytest.raises(DxfParseError, match="Invalid DXF header"):
        parser.parse(p)
```

### 4.1 后端 API 集成测试

使用 `httpx.AsyncClient` + FastAPI TestClient：

```python
# python/tests/integration/test_lnn_api.py
import pytest
from httpx import AsyncClient
from app.main import app

@pytest.mark.asyncio
async def test_lnn_infer_endpoint_success():
    async with AsyncClient(app=app, base_url="http://test") as ac:
        # 先登录拿 token
        token = await _login(ac, "admin", "admin")
        headers = {"Authorization": f"Bearer {token}"}

        resp = await ac.post(
            "/api/v1/lnn/infer",
            headers=headers,
            json={"model_id": "cfc_v3", "input": {"features": [1, 2, 3]}},
        )

    assert resp.status_code == 200
    body = resp.json()
    assert "prediction" in body
    assert body["model_id"] == "cfc_v3"
    assert body["confidence"] >= 0.0

@pytest.mark.asyncio
async def test_lnn_infer_invalid_model_returns_4001():
    async with AsyncClient(app=app, base_url="http://test") as ac:
        token = await _login(ac, "admin", "admin")
        resp = await ac.post(
            "/api/v1/lnn/infer",
            headers={"Authorization": f"Bearer {token}"},
            json={"model_id": "nonexistent", "input": {}},
        )

    assert resp.status_code == 400
    body = resp.json()
    assert body["error_code"] == "E5001"
    assert "model not found" in body["message"].lower()
```

### 4.3 SSE 集成测试

```python
import pytest
import httpx

@pytest.mark.asyncio
async def test_sse_progress_stream():
    async with httpx.AsyncClient(base_url="http://localhost:8000") as client:
        # 1. 创建任务
        job = await client.post("/api/v1/jobs", json={"type": "dxf_pipeline", "file_id": "abc"})
        job_id = job.json()["id"]

        # 2. 订阅 SSE
        events = []
        async with client.stream("GET", f"/api/v1/jobs/{job_id}/events") as resp:
            async for line in resp.aiter_lines():
                if line.startswith("data:"):
                    events.append(line[5:].strip())
                if len(events) >= 3:
                    break

    assert len(events) >= 3
    assert "progress" in events[-1]
```

### 5.2 示例：DXF 端到端流程

```typescript
// e2e/dxf-pipeline.spec.ts
import { test, expect } from '@playwright/test'
import path from 'path'

test.describe('DXF → NC 端到端', () => {
  test('从上传到下载 G 代码', async ({ page }) => {
    // 1. 登录
    await page.goto('/login')
    await page.fill('[data-testid="username"]', 'test_user')
    await page.fill('[data-testid="password"]', 'test_pass')
    await page.click('[data-testid="login-btn"]')
    await expect(page).toHaveURL('/projects')

    // 2. 新建工程
    await page.click('[data-testid="new-project"]')
    await page.fill('[data-testid="project-name"]', 'E2E 测试工程')
    await page.click('[data-testid="create-btn"]')

    // 3. 上传 DXF
    const dxfPath = path.resolve(__dirname, 'fixtures/sample.dxf')
    await page.setInputFiles('[data-testid="dxf-upload"]', dxfPath)

    // 4. 等待解析完成
    await expect(page.locator('[data-testid="parse-status"]')).toHaveText(
      '已就绪',
      { timeout: 30_000 }
    )

    // 5. 启动工艺规划
    await page.click('[data-testid="start-planning"]')

    // 6. 等待进度 100%
    await expect(page.locator('[data-testid="progress-bar"]')).toHaveAttribute(
      'aria-valuenow', '100', { timeout: 60_000 }
    )

    // 7. 导出 NC
    const [download] = await Promise.all([
      page.waitForEvent('download'),
      page.click('[data-testid="export-nc"]'),
    ])
    expect(download.suggestedFilename()).toMatch(/\.nc$|\.gcode$/)
  })
})
```

## 10. CI 集成

`.github/workflows/ci.yml` 中的测试阶段：

```yaml
test:
  runs-on: ubuntu-latest
  strategy:
    matrix:
      python-version: ['3.11']
  steps:
    - uses: actions/checkout@v4
      with: { lfs: true }

    - uses: actions/setup-python@v5
      with: { python-version: ${{ matrix.python-version }} }

    - name: 安装依赖
      run: |
        cd python
        pip install -e ".[dev,test]"

    - name: 单元 + 集成
      run: |
        cd python
        pytest --cov=app --cov-report=xml --cov-fail-under=80

    - name: 上传覆盖率
      uses: codecov/codecov-action@v4
      with: { file: python/coverage.xml }

e2e:
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4
    - uses: actions/setup-node@v4
      with: { node-version: 20 }

    - name: 安装并运行 E2E
      run: |
        pnpm install
        docker compose up -d
        pnpm test:e2e

    - uses: actions/upload-artifact@v4
      if: always()
      with:
        name: playwright-report
        path: playwright-report/
```

## 13. 故障排查

| 症状 | 排查 | 解决 |
|------|------|------|
| `pytest` 找不到模块 | `pip install -e .` 未执行 | 重装并激活 venv |
| `asyncpg` 报错 | DB 未启动 | `docker compose up -d postgres` |
| Playwright 浏览器缺失 | 未 install | `pnpm exec playwright install` |
| 覆盖率报告打不开 | 路径错误 | `coverage-reports/backend/index.html` |
| E2E 超时 | 后端未启动 | 检查 webServer 配置 |
