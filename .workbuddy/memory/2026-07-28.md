1. **修复 `from __future__ import annotations` 前向引用崩溃**
   - 根因：该 import 使端点参数注解变为字符串；当端点被外部模块装饰器 `@limiter.limit` 包裹时，函数 `__globals__` 被替换为 limiter 模块，Pydantic 解析本地定义的 Pydantic 模型（`ExplainProcessRequest` 等）失败 → worker 全部死亡。
   - 用 AST 扫描全 `app/` 树，精确定位 6 个危险文件（future import + limiter 包裹 + 本地模型参数，且确认无前向引用风险），删除该行。
   - 文件：`api/v1/auth.py`、`api/v1/process_explainer.py`、`api/v1/signal_fusion_kb.py`、`api/v1/agent_gateway/inference.py`、`api/v1/agent_gateway/training.py`、`api/v1/nl2cad/routes.py`。

2. **修复 JWT 启动安全门**
   - `auth/security.py` 强制要求 `LNN_JWT_SECRET` 非空且 ≥32 字符，否则拒绝启动。`.env.sqlite` 中该值为空。
   - 生成 64 字符强密钥写入 `.env.sqlite`；修正了 `.env.sqlite` 中"留空自动生成临时密钥"的误导性注释（代码实际拒绝空值）。

## 端口冲突修复：动态端口 + 前端 baseURL 跟随（2026-07-28 晚）
**故障**：安装版首启卡"启动中"。根因：Docker Desktop（com.docker.backend.exe）把 lnn-api 容器映射到宿主 8765，桌面 sidecar 绑定失败 → wait_ready 45s 超时 → 前端 status 停在 starting。
**关键架构事实**：前端业务 API 全部相对路径，axios 无 baseURL；vite proxy 仅 dev 生效；Tauri 生产模式必须运行时设 baseURL=http://127.0.0.1:{实际端口}（CSP 已放行 127.0.0.1:*）。EventSource(SSE) 不走 axios，需单独解析 URL。
**修复（4 文件）**：
1. `src-tauri/src/sidecar.rs`：`start()` spawn 前 `find_available_port(8765)`——TcpListener 探测，占用则 +1 递增（最多 +20），再兜底 OS 随机端口；实际端口写回 `state.port`，与 `--port`/`LNN_PORT`/wait_ready/emit_state 全程一致。新增 `port_is_free`/`find_available_port` 两个私有函数（文件尾部）。
2. `src/utils/http.ts`：新增 `setBackendPort(port)`（设 axios `defaults.baseURL`，幂等）、`getBackendPort()`、`resolveBackendUrl(path)`（供 SSE/fetch 用；端口未设置时原样返回相对路径以兼容 vite dev proxy）。
3. `src/composables/useBackendStatus.ts`：新增 `applyState()` 统一状态写入口，替换全部 5 处 `Object.assign`，每次收到 state 快照/事件即 `setBackendPort(state.port)`。App.vue 根组件已用该 composable，端口同步在启动最早期生效。
4. `src/composables/useEventSource.ts` + `useWorkflow.ts`：SSE URL 均包 `resolveBackendUrl()`。
**验证**：`cargo check` 通过（1m33s）；`pnpm type-check`（vue-tsc）通过。重打包 `pnpm tauri build` 后台进行中（task sCunuB）。
